## ADR-0001: База — `eyriehq/plane-plus`, не upstream `makeplane/plane`

**Контекст.** Нужен agent-first опыт (App Rail, Wiki, AI, first-class epics, API-key auth) —
это EE/коммерческий слой Plane (`@/plane-web/`), в upstream Community отключён. Портировать
EE на upstream — бесконечный труд.
**Решение.** Брать `eyriehq/plane-plus` (AGPL-форк, переоткрывший EE-фичи) как базу ветки `plus`.
**Последствия.** Фичи Plus из коробки; цена — отставание от upstream/preview по «свежести»
(база ≈ Plane 1.3.1). Свежие фиксы Plane приходят через eyriehq (мержат upstream к себе).
Часть EE без модели (Initiatives) — в нашем GraphQL стабы.

## ADR-0002: Мобильный бэкенд — реализовать GraphQL-контракт Cloud (ariadne, schema-first)

**Контекст.** Официальное приложение ходит в коммерческий GraphQL Cloud (`api.plane.so/graphql/`),
которого в self-hosted нет (EE-only). Без него приложение не работает. Варианты:
(a) форкнуть/патчить приложение под REST; (b) реализовать GraphQL-контракт на сервере.
**Решение.** (b) — ariadne schema-first: SDL Cloud (снят интроспекцией) как контракт +
резолверы поверх наших Django-моделей, логику реплицируем из штатных REST-вью Plane. Глобальный
smart-fallback (camelCase→snake_case, FK→`_id`) покрывает тривиальные поля; вручную — только
вычисляемые/M2M/вложенные. Непривязанные — `install_safe_query_defaults` (безопасный пустой дефолт).
**Последствия.** Приложение «не замечает» подмены; не трогаем APK (обновления приложения не
ломают). Грабли: (1) молчаливые стабы проходят «нет ошибок» — аудитить сверкой с SDL/БД;
(2) **non-null поля, которых нет на модели** → smart-fallback None → краш всего запроса
(класс багов, см. 03-graphql-gateway). Полнота — задача (158 Query + 183 Mutation полей).

## ADR-0003: Баг стиков на cold-start — КЛИЕНТСКИЙ, сервером не чинится (закрыто)

**Контекст.** На self-hosted home-стики на холодном старте — вечный скелетон; на Cloud
работают. Потрачено много на серверные гипотезы.
**Решение/вывод (доказано frida + логами + декомпилем).** Это **клиентская гонка
монтирования**: `_HomeStickiesWidgetState` не слушает появление воркспейса (бейлит на
`currentWorkspace==null` и не рефетчит); на self-hosted `SelfHostedVersionInfoWrapper`-гейт
меняет тайминг монтирования. Гипотеза «замедлить `/api/instances/`» **ОПРОВЕРГНУТА** (двигает
оба синхронно, порядок не переворачивает) и откатана.
**Последствия.** Детерминированно чинится только на клиенте (патч APK) ИЛИ самохилится на
тёплом старте / переключении вкладки / pull-refresh. Сервером — НЕ продолжать копать. Детали —
PARITY-AUDIT.md, ADR закрыт.

## ADR-0004: Модули-области GraphQL — самодостаточные файлы, грузятся ПЕРЕД ядром

**Контекст.** ~116 непривязанных Query-полей (epics/initiatives/intake/pages/collections/
assets/cycles-modules/issue-extras/invites) — нужно реализовать массово, в идеале параллельно
(агент на область), без конфликтов правок.
**Решение.** Каждая область — отдельный самодостаточный файл `areas/<x>.py` (свои QueryType/
MutationType/ObjectType + `BINDABLES`). ariadne мёржит инстансы. `AREA_BINDABLES` в
`make_executable_schema` идут **ПЕРЕД** core RESOLVERS/MUTATION_BINDABLES → на полях, что
область перепривязала и которые уже есть в ядре (эпик-мутации, initiativesCount), выигрывает
established core.
**Последствия.** Параллельная реализация без конфликтов; гейт — локальная сборка схемы
(Django + ariadne) ловит плохие привязки/импорты ДО деплоя (одна ошибка роняет весь шлюз).

## ADR-0005: Диагностические логи за env-флагом; `csrf_exempt` оставлен

**Контекст.** Реверс требовал логировать запросы (`[MOBILE-GQL]`/`[MOBILE-AUTH]`); для прода
шумно. `csrf_exempt` на мобильных эндпоинтах.
**Решение.** Логи за `MOBILE_DEBUG_LOG=1` (по умолчанию off; включается env без правки кода).
`csrf_exempt` ОСТАВЛЕН — функционален (приложение/мобильный-флоу не шлют Django-CSRF на
`/graphql/` и `/auth/mobile/*`; убрать = сломать вход).
**Последствия.** Прод чистый, отладочный рычаг под рукой. csrf_exempt — осознанно (не «забытая» дыра).

## ADR-0006: История ветки `plus` сжата squash'ем; деплой через образ, не git

**Контекст.** Phase 4/4b накопили ~46 коммитов с тупиковыми экспериментами (стики).
**Решение.** Squash в 5 чистых коммитов (feat(mobile-auth)/feat(mobile-graphql)/test/
docs(mobile)/docs(fork)) + force-push. Перед squash — бэкап-ветка; после — проверка, что
код байт-в-байт идентичен (только доки переформатировал линтер). Прод тянет ОБРАЗ `:plus`,
а не git-историю — squash для гигиены, на деплой не влияет.
**Последствия.** Чистая история. Деплой = redeploy compose (подтягивает свежий `:plus`).
